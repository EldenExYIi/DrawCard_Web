# Draw LevelSystem

关卡系统版本入口。每个关卡 MVP 使用独立文件夹保存。

## Level 001

`Level_001/index.html` 实现首个完整关卡循环：

- 开始游戏与战士角色选择。
- 40c 开局，商店将卡牌、抽牌策略与武器分栏随机刷新。
- 只使用知识库图鉴中的中立卡牌与战士卡牌。
- 抽牌策略按实体牌管理，库存前六张按顺序循环执行；初始均为“筹备”。
- 收录哑铃、双刀、盾牌、匕首、大剑、炽焰之锤与石中剑，并按玩家排列顺序封装。
- 每个商店商品只能购买一次，可花费 2c 刷新整间商店。
- 采用 V1 战斗规则：抽牌、出牌、弃牌、武器封装与循环牌链。
- 以五份 Build 作为战力校准种子，通过同一战斗引擎模拟筛选，逐轮生成第 1–20 轮参考 Build 池。
- 玩家随机匹配同轮参考 Build；每场结算后记录玩家当轮 Build，并加入该轮本局数据池。
- 战斗支持 0.1x、0.5x、1x、2x 与 4x 倍速。
- 胜利奖励 15c，失败奖励 12c。
- 根据离开商店时的金币计算利息，每 5c 获得 1c，最多 5c。
- 累计三次失败后结束，并显示本局胜场。

## Level 002

`Level_002/index.html` 是基于 V2 战斗策划案制作的完整关卡实验版本：

- 保留商店、构筑、自动战斗、结算和三败终局的关卡循环，共 20 轮。
- 4c 起步；基础收入每两轮增加 1c，胜负奖励每三轮增加 1c，失败奖励固定比胜利奖励多 2c。
- 商店按轮次调整普通、稀有、史诗、传说出现概率，阻止前几轮直接获得完整高稀有体系。
- 使用拖拽调整整条牌链顺序、武器位置和卡牌卡位，不再使用上下移动按钮。
- 首链可自由放置行动牌与策略牌；后续链战前只能预放策略牌。
- 策略牌必须封装进牌链，并在循环到自身时才执行抽牌、筛选、弃牌和进入 FIFO 待封装区。
- 新牌链封装后，所有旧牌链的单轮执行耗时翻倍。
- 程序化生成 200 种行动牌、50 种策略牌和 30 把武器，覆盖连击、蓄力、格挡、锻造和流血五套体系。
- 生成 20 轮 × 每轮 10 组对战数据；每条数据保留收入、刷新、购买历史并通过可购买性校验。
- 对战使用同一战斗引擎测算 DPS，并从同轮数据中匹配与玩家 DPS 邻近的对手。

## 运行

直接打开 `index.html` 进入版本库，再选择 Level 001 或 Level 002。

Level 001 本身也是单文件页面，可以直接打开：

```text
Level_001/index.html
```

Level 002 同样可以直接打开：

```text
Level_002/index.html
```
